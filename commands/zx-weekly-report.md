# zx-weekly-report — 周报更新

根据当前会话产出更新 `/home/devtrump/zx-projects/docs/weekly-report.md`。

## 使用方式

```
/zx-weekly-report          → 根据本次会话产出，叠加到当前周的条目里
/zx-weekly-report new      → 新建下一周的条目（新增 # YYYY-MM-DD 块）
/zx-weekly-report <描述>   → 只补充指定内容，不自动推断
```

## ⚠️ 关键判断：当前周 vs 下周/未来周

**优先解析用户意图，再决定模式：**

| 用户说了什么 | 正确行为 |
|---|---|
| "叠加到本周" / 无特别说明 | 叠加模式：追加到文件最新块 |
| "下周周报" / "next week" / "写下周" | **新建模式**：计算下一个周五日期，创建新 `# YYYY-MM-DD` 块 |
| "下下周" / "两周后" | **新建模式**：计算对应周五日期，创建新块 |
| 指定了未来日期 | **新建模式**：用指定日期所在周的周五 |

**绝对不能把"下周/未来周"的内容追加到当前最新块里。**

新建模式与叠加模式的区别：新建模式在文件末尾新增完整的 `# YYYY-MM-DD / ## 本周总结 / ## 下周计划` 结构，序号从 1 开始；叠加模式只在现有块的已有条目后追加，序号续上。

## 写作规则

1. **每条一行**，不换行，不写长句，**每条字数不超过 45 字**（含标点）；超出必须精简，不得拆成两条
2. **格式**：`序号、做了什么：结果/进度，完成度%`
3. **不写 AI 味**：不用"通过…实现了…"这类句式，直接写做了啥
4. **侧重产出**：有代码改动、有发布、有结论、有联调推进才算一条
5. **完成度**：能确认的写 100%，不确定的写实际进度 %
6. **下周计划**：1-3 条，简短，写实际要跟进的事
7. **只写对公司有直接业务价值的产出**，以下一律不写：本地环境搭建、开发工具折腾、AI技能/脚本工具建设、基础设施迁移（仓库迁移、symlink配置、工具工程化等）、调试过程记录
8. **本周总结最少 3 条**：不足 3 条时，结合会话上下文和上周遗留事项补充到 3 条为止
9. **本周总结只写确定性产出**：禁止出现"预计"、"预估"、"大约"、"应该"等不确定词汇；"预计 xx%"只允许出现在 `## 下周计划` 里
10. **内容不得与近三周高度重复**：写入前先回顾文件里最近 3 个周报块的本周总结，若新条目的核心动词+对象与已有条目高度雷同（如同一个模块/接口反复出现"联调支持"、"跟进验证"），必须换角度或换素材来源，优先从以下渠道挖新产出：① 本次 AI 对话里未写进来的其他改动；② `git log` 近期提交记录里被忽略的有价值提交；③ 项目文档/代码里自己发现的新问题或优化点。**宁可条目少也不写重复水词。**

## 格式规范

- **日期**：每个周报块标题为 `# YYYY-MM-DD`，日期为**当周周五**，精确计算，不能估算
- **块间距**：相邻两个周报块之间**空一行**（上一块最后一行后空一行，再写下一块 `# YYYY-MM-DD`）
- **下周计划**：`## 下周计划` 与上方本周总结内容之间**不空行**

## 两种模式

### 叠加模式（默认）
找到文件里最新的 `# YYYY-MM-DD` 块，**只在已有条目后面追加**，序号续上。
绝对不修改、不删除、不重写已有任何条目，包括本周总结和下周计划。

### 新建模式（new）
在文件末尾追加新的周块：
```
# YYYY-MM-DD
## 本周总结
1、...

## 下周计划
1、...
```

## 执行步骤

1. 读取 `/home/devtrump/zx-projects/docs/weekly-report.md`，找最新日期块
2. 回顾本次会话的实际产出（代码改动、发布、排查结论、联调推进、工具建设等）
3. 按规则提炼条目，叠加或新建
4. **强制检查：本周总结条数是否 ≥ 3**
   - 叠加模式：已有条目 + 本次新增，合计 ≥ 3 条即可
   - 新建模式：本次内容通常只有 1-2 条，**必须**从上周的"下周计划"和会话上下文里补足到 3 条，不得跳过
   - 补充来源优先级：① 本次会话其他产出 → ② 上周下周计划里的跟进项 → ③ 本周已知在推进的事项
5. **强制去重：与近 3 周内容比对**
   - 读取文件里最近 3 个 `# YYYY-MM-DD` 块的本周总结
   - 逐条检查新写的条目：核心动词 + 对象是否与近 3 周某条高度雷同
   - 若有重复，必须换素材：按顺序尝试 → git log 近期提交 → 项目文档/代码新问题 → 本次对话其他细节产出
   - 实在无新素材，宁可该条不写，不写重复水词
6. 写入文件，输出本次新增的内容供确认
