# v0 — 高转化页面生成协议

**每次调用此 skill，agent 必须完整走完「执行协议」，不得跳步，不得让用户自己拼 prompt。**

---

## 核心目标（每次生成只有一个终极目的）

```
让用户付钱。
所有视觉、文案、交互、效果，都是这一个目的的服务者。
不是为了好看，不是为了炫技，是为了让用户掏钱包。
```

## 设计 DNA（五维强制规则，每次生成自动内嵌）

---

### D1 · 视觉吸引力：3秒内注意力全收割

**目标感受：用户打开页面，像走进赌场——环境本身在勾引，不是真赌场，是那种「进来就不想走」的氛围磁场。**

#### 首屏 800ms 加载序列（页面活起来的关键）

用户打开页面的前800ms决定他是否继续看。必须按以下时序：

```
0ms     背景色 #0a0a0a 立即出现（无白屏闪烁）
0-200ms 背景粒子/光晕淡入（opacity 0→0.6），用户感知到「有东西在动」
200ms   Hero 标题滑入（y:40→0，opacity:0→1，duration:600ms，ease:[0.16,1,0.3,1]）
280ms   副标题跟入（stagger +80ms）
360ms   CTA 按钮出现，shimmer光线立即开始循环
400ms   cursor spotlight 激活（鼠标在哪，光就在哪）
600ms   页面完全稳定，用户进入探索状态
```

#### 首屏必须包含的视觉钩子（Pattern Interrupt）

用户每天看几百个页面，必须有一个「意外的东西」让他停下来：

```
选项A：动态标题词替换（Typewriter cycling：「让会议」→「让演讲」→「让想法」→「被记住」）
选项B：光源跟随鼠标（cursor glow，600px radial，用户移动鼠标就有反应，建立互动感）
选项C：数字在进入视口时滚动到最终值（「0→12,847」的过程让人停下看完）
选项D：视频/动态背景（低帧率loop，5秒，无声，暗色调不抢文字）

→ agent 必须选其中至少1个，作为首屏「停顿钩子」
```

#### Dark Luxury 视觉系统（固定，每次全带）

```css
/* 背景层级（由下到上叠加） */
Layer 0  background: #0a0a0a
Layer 1  noise: SVG feTurbulence，opacity:0.035（颗粒感 = 品质感）
Layer 2  grid:  background-image: linear-gradient(rgba(255,255,255,0.04) 1px, transparent 1px)
                background-size: 40px 40px（空间感）
Layer 3  hero glow: radial-gradient(ellipse 80% 50% at 50% -10%,
                    [品牌色/15%], transparent)（焦点光晕）
Layer 4  内容区
Layer 5  cursor spotlight: radial-gradient(600px at [mouseX]px [mouseY]px,
                           [品牌色/12%], transparent 70%)（交互层）

/* 色彩规则 */
--bg-base:     #0a0a0a
--bg-surface:  #111118（卡片底）
--bg-elevated: #1a1a2e（hover/高亮）
--brand:       [从用户信息提取，默认 #6366f1]
--text-hi:     rgba(255,255,255,0.95)
--text-mid:    rgba(255,255,255,0.55)
--text-lo:     rgba(255,255,255,0.30)
--border:      rgba(255,255,255,0.08)
--border-brand:[品牌色 rgba at 0.30]

/* 排版精确值 */
hero-title:    font-weight:900，clamp(52px,7vw,108px)，line-height:1.05
sub-title:     font-weight:400，clamp(16px,2vw,22px)，color:--text-mid

```

#### 「赌场感」的具体技术构成

```
① 多层同时运动（页面在「呼吸」）：
   粒子漂移（速度极慢，每秒2-3px）
   + cursor glow 实时跟随
   + 卡片 hover 时浮起+边框发光
   以上三者同时运行，用户感受到「这个世界有生命」

② 有机 easing（禁用 linear/ease-in-out）：
   主动效：cubic-bezier(0.16, 1, 0.3, 1)   → 快出慢收，弹性感
   卡片交互：cubic-bezier(0.4, 0, 0.2, 1)  → 流畅自然
   弹窗/大元素：spring(stiffness:400, damping:30) → 有重量感

③ 深度系统（z轴感）：
   卡片 default:  translateY(0) scale(1.00) box-shadow:none
   卡片 hover:    translateY(-6px) scale(1.02)
                  box-shadow: 0 20px 60px rgba(0,0,0,0.5),
                              0 0 0 1px [品牌色/30%]
   transition: 300ms cubic-bezier(0.16,1,0.3,1)

④ 品位控制（奢华 ≠ 堆砌）：
   同屏运动元素 ≤ 3个（背景不算）
   颜色 ≤ 2种（背景色系 + 1个品牌色）
   字体 ≤ 2种（标题 + 正文）
   每个效果必须能回答：「它在推进用户注意力向哪里移动？」
   回答不了的效果，删掉。

⑤ 性能预算（卡顿 = 反奢华）：
   动效帧率必须维持 60fps
   粒子数量：桌面 ≤ 80个，移动端 ≤ 30个
   禁止同时运行超过2个 CSS animation + 1个 JS animation
   使用 will-change: transform 提前告知浏览器
   scroll reveal 用 Intersection Observer，不用 scroll 事件监听
```

#### 效果选择矩阵（agent 查表执行，不自由发挥）

| 区域 | 必选 | 条件选 |
|------|------|--------|
| Hero | cursor spotlight + 加载序列stagger | 有数据→粒子背景；无设计参考→typewriter |
| 功能区 | hover深度系统 + scroll reveal | ≥4功能→Bento grid；<4→卡片横排 |
| 数据/指标 | CountUp滚动 + 进入视口触发 | 总是加，无论如何 |
| CTA按钮（主） | shimmer光线扫过 + hover translateY(-2px) | 总是加 |
| 定价卡片 | glassmorphism + 中间档scale(1.05) | 总是加 |
| 全局section | Framer Motion whileInView stagger | 总是加 |
| 背景 | noise texture + grid + hero glow | 总是加 |

### D2 · 文案心理占位：过目不忘，用户自己说「这就是我要的」

**目标：用户看完标题，脑子里有一块地方被占了，以后再看同类产品都会拿你做参照。**

#### 一句话定位公式（所有文案的根基）

```
[我们是] 唯一一个 [针对谁] [做什么事] [而不是竞品那样] 的 [产品类型]

示例：
「唯一一个让非设计师也能在10分钟内发布高转化落地页的工具，
 而不是又一个模板编辑器」

→ 这句话不一定出现在页面上，但是所有文案的主脑，agent 必须先确立它
```

#### 标题可记忆性规则（让标题像口头禅一样传播）

```
规则1：具体 > 抽象
  ❌「提升工作效率」
  ✅「每周省下11小时会议时间」

规则2：数字比形容词有力
  ❌「大幅提升转化率」
  ✅「转化率从1.2%到7.8%」

规则3：对立/反差制造张力
  ❌「简单好用的录音工具」
  ✅「会议录了，但没人听——直到你用这个」

规则4：节奏感（可以大声读出来不别扭）
  ❌「基于AI的智能会议纪要生成解决方案」
  ✅「开完会，它替你记住一切」

规则5：用户语言，不用产品语言
  ❌「多模态AI语音识别引擎」
  ✅「你说，它写，不用复听」
```

#### Enemy Framing（定义敌人，清晰自己是谁）

```
每个页面必须隐含一个「反派」：
→ 不是竞品（不要点名），是旧的方式/旧的痛苦

示例：
「告别在会议结束后疯狂回忆刚才说了什么」
「你不需要再为「谁说要负责这件事」争来争去」
「让AI来做烦人的部分」

→ 用户看到反派，立刻觉得「就是它！你懂我！」，心理占位完成
```

#### 核心信息3次重复（植入记忆）

```
同一个核心价值，在页面上用3种形式出现：
形式1  Hero标题（情感化，感性）
形式2  功能区某条（功能化，理性验证）
形式3  终极CTA前的一句话（总结化，行动触发）

示例（核心价值：「开会不用记笔记了」）：
形式1：「开完会，它替你记住一切」（Hero）
形式2：「自动生成会议纪要，包含行动项和负责人」（功能区）
形式3：「从今天起，你可以专心开会了」（终极CTA前）
```

#### 文案精度要求（agent 生成时逐条检查）

```
Hero标题   ≤10字（中文）/ ≤8词（英文）
副标题     ≤25字，1句，说清楚「谁用+得到什么结果」
CTA按钮    ≤6字，动词+结果，禁用：了解/探索/体验/注册/提交
功能描述   ≤12字/条，「让你[结果]」格式，禁用「支持/提供/具备」
引语       必须有具体结果+真名+职位，禁用泛化评价
错误示范   「欢迎使用」「功能强大」「一站式平台」「赋能」「生态」→ 全删
```

### D3 · v0 高级效果占比：高端大气上档次，低调奢华有内涵

**原则：一个用得极好的效果，胜过十个用得平庸的效果。每个效果必须服务叙事。**

#### 效果叙事对应表（每个效果有存在理由）

```
cursor spotlight   → 告诉用户：「这个页面在感知你」→ 建立互动感和尊重感
加载序列stagger    → 告诉用户：「内容是精心安排给你的」→ 暗示品质
CountUp 数字       → 告诉用户：「这些数字是真实的，刚刚计算完」→ 强化可信度
卡片hover浮起      → 告诉用户：「点这里」→ 降低交互摩擦
shimmer CTA        → 告诉用户：「这个按钮在等你」→ 持续召唤行动
scroll reveal stagger → 告诉用户：「你在往前走，有新内容在等你」→ 鼓励继续探索
粒子背景           → 告诉用户：「这个品牌有能量」→ 氛围渲染
gradient text      → 告诉用户：「这是最重要的信息」→ 视觉强调
```

#### 代码级实现（agent 直接塞进 prompt，保证 v0 输出到位）

```tsx
// ① cursor spotlight（hero必加）
const [pos, setPos] = useState({ x: 0, y: 0 })
useEffect(() => {
  const update = (e: MouseEvent) => setPos({ x: e.clientX, y: e.clientY })
  window.addEventListener('mousemove', update)
  return () => window.removeEventListener('mousemove', update)
}, [])
// 在hero容器上：
style={{ background: `radial-gradient(600px at ${pos.x}px ${pos.y}px,
  rgba(99,102,241,0.12), transparent 70%)` }}

// ② shimmer CTA button（主CTA必加）
// className="relative overflow-hidden group"
// ::after { content:''; position:absolute; inset:0;
//   background: linear-gradient(105deg, transparent 40%,
//     rgba(255,255,255,0.15) 50%, transparent 60%);
//   transform: translateX(-100%);
//   transition: transform 500ms ease; }
// group-hover::after { transform: translateX(100%) }

// ③ Framer Motion stagger（全局section必加）
const container = {
  hidden: {},
  show: { transition: { staggerChildren: 0.08 } }
}
const item = {
  hidden: { opacity: 0, y: 30 },
  show: {
    opacity: 1, y: 0,
    transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1] }
  }
}
<motion.div variants={container} initial="hidden" whileInView="show" viewport={{ once: true }}>
  {items.map(i => <motion.div key={i} variants={item}>...</motion.div>)}
</motion.div>

// ④ CountUp（数据区必加）
// 用 react-countup + useInView
// <CountUp end={12847} duration={2} separator="," useEasing enableScrollSpy scrollSpyOnce />

// ⑤ 粒子背景（hero背景可选，canvas纯手写）
// 50-80个点，随机速度 0.3-0.8px/frame，连线距离<120px opacity随距离衰减
// requestAnimationFrame loop，移动端减半粒子数
```

#### 效果组合原则（多个效果如何协调成整体高级感）

```
层次分离原则：
  背景层（粒子/grid/noise）→ 慢速、低对比、永远在动
  中间层（卡片/区块）      → 用户触发才动（hover/scroll进入）
  前景层（标题/CTA）       → 进场动一次，之后静止，不抢注意力
  交互层（cursor glow）    → 实时响应，但不能比前景亮

节奏控制原则：
  同屏不能有超过2个元素在同时运动（背景不算）
  scroll reveal 的触发点错开（不要所有元素同时进入）
  每个区域有一个"主角效果"，其他效果让位

整体感营造：
  所有动效用同一条 easing 曲线（cubic-bezier(0.16,1,0.3,1)）→ 风格统一
  所有 glow 用同一个品牌色 → 视觉连贯
  所有边框用同一透明度规范（--border 和 --border-brand 两种）→ 系统感
  用户从头滑到尾，感受到的是「一部电影」，不是「一堆零件」
```

#### 效果禁区（agent 看到就拒绝）

```
transition: all 0.3s ease           → 禁止，必须精确指定属性
transform: rotate + 无意义旋转装饰   → 禁止，没有叙事目的
多个颜色渐变同时出现在前景           → 禁止，视觉噪音
字体粗细差距<200（如400和500并存）   → 禁止，层级不清
背景动效帧率<30fps                   → 禁止，卡顿=廉价感
```

### D4 · 心理战术有效性：从感知到付费，每步都在推进

**每个心理战术有精确的触发位置和执行方式，不是「有就好」，是「对的时间对的地方」。**

#### 战术触发时序（按scroll位置）

```
[首屏 · 0-100vh]  Pattern Interrupt 钩子 → 锁定注意力
                  Enemy Framing → 「你懂我」的共鸣
                  单一CTA → 趁热打铁，提供立刻行动的出口

[信任区 · 100-200vh]  社会认同 → 理性大脑开始质疑时出现
                       具体数字 + 公司logo + 真人引语
                       CountUp 数字在进入视口时滚动 → 制造「刚算完」的现场感

[解决方案区 · 200-300vh]  功能≤4条，每条说「结果」不说「功能」
                           损失厌恶语言：「不用再XXX」「永远不会XXX」
                           与Enemy Framing呼应：「和XXX方式说再见」

[定价区 · 300-400vh]  锚定效应：最高档出现在最左边（或最先渲染）
                       中间档视觉强调：scale(1.05) + 「最受欢迎」badge
                       稀缺感：「早期价格，本月仅余N个名额」（N<20才可信）
                       渐进承诺：最低档叫「免费开始」，不要信用卡

[终极CTA · 最后一屏]  峰终定律：情感最高点，不是信息堆砌
                       重复首屏的痛点（完成闭环）
                       唯一CTA，没有任何分叉链接
```

#### 沉默异议处理（用户脑子里的话，他不会说出口）

```
异议1：「这真的有用吗？」
→ 处理方式：具体化结果（不是「效果好」，是「第一周3个付费用户」）

异议2：「太贵了」
→ 处理方式：锚定+转换（「雇一个全职设计师要$8000/月，这个$29」）

异议3：「我以后再说」
→ 处理方式：稀缺+损失（「早期价格明天结束」/「仅余12个名额」）

异议4：「我不确定适不适合我」
→ 处理方式：渐进承诺（「不用信用卡，免费试14天」）

异议5：「万一用了没效果」
→ 处理方式：去风险承诺（「30天无理由退款」，放在CTA旁边，不是页脚）
```

#### 信任叠加层次（按强度从弱到强）

```
L1 视觉信任   → 设计本身的质感（Dark Luxury = 「这家公司很认真」）
L2 数字信任   → 具体可验证的数字（用户数、成功案例数、时间）
L3 社会信任   → 真实的人说真实的结果（头像+名字+职位+公司）
L4 权威信任   → 知名公司logo使用（灰度展示，尊重）
L5 去风险信任 → 退款保障+免费试用（放在CTA附近，不埋在页脚）

→ 页面上5层都要有，缺哪层都会漏用户
```

### D5 · 交互流程与转化一致性：每个元素只服务一个目的——让用户付钱

**终极审计原则：页面上的每个元素，必须能回答「它在把用户推向CTA，还是在分散注意力？」后者一律删除。**

#### 完整转化漏斗

```
进入页面
  ↓
3秒内被钩子抓住（D1）
  ↓
标题产生共鸣「这说的是我」（D2）
  ↓
信任建立「别人用了有效果」（D4 L2-L5）
  ↓
异议消除「没风险，先免费试」（D4 沉默异议）
  ↓
单一CTA行动「开始赚钱」
  ↓
转化完成

→ 漏斗每个步骤在页面上必须有对应区域，顺序不能乱
```

#### 泄漏点审计（agent 生成完必须检查）

```
□ 导航栏有超过5个链接？ → 精简，非必要不放，博客/文档不出现在主导航
□ 页面中间出现了第二个CTA指向不同方向？ → 删掉，只留一个主CTA
□ Footer 有大量链接分散注意力？ → landing page footer只留版权和隐私政策
□ 有「了解更多」之类无目的链接？ → 全删
□ 功能介绍写了超过4条？ → 精简到4条，超出的放FAQ
□ 有没有提供邮件捕获作为转化fallback？ → 必须有（用户不付钱，至少留邮件）
□ 退款保障有没有放在CTA旁边？ → 必须在CTA下方1-2行内，不能只在页脚
□ 移动端CTA按钮够不够大够不够高？ → height≥52px，width:100%
```

#### 邮件捕获作为转化Fallback

```
→ 针对「不准备付钱但有兴趣」的用户
→ 放置位置：hero CTA下方一行（「还没准备好？先看看案例 →」）
→ 触发方式：modal 或独立 section，只问邮件，不问姓名
→ 价值交换：免费资源/案例/模板，不是「订阅我们的新闻」
```

## Agent 执行协议（调用 /v0 必须走完）

### Step 1 · 任务分类

```
「改样式/颜色/文案/间距」？
  → Design Mode（Option+D），Apply才计费，直接告知操作步骤，结束

「代码报错/bug」？
  → Fix with v0（20次/天免费），先用免费额度

「生成新页面/组件」？
  → 继续 Step 2

「用户要浅色主题/B2B后台/非landing page」？
  → 保留D2/D4/D5全部规则，仅替换D1色彩系统为浅色方案
  → 继续 Step 2
```

### Step 2 · 品牌色提取

```
① 用户本次提到颜色 → 直接用
② 历史信息/文件中有品牌色 → 用那个
③ 完全没有信息 → 默认 #6366f1，输出时注明「可告诉我你的品牌色」

提取到后计算：
glow  = 品牌色 opacity 0.12-0.15
border = 品牌色 opacity 0.30
gradient = 品牌色 → 色相偏移+30° → 渐变文字
```

### Step 3 · 选模型

