# v0 — 高转化页面生成协议

**每次调用必须完整走完「执行协议 Step1-5」，不得跳步，不得让用户自己拼 prompt。**

## 核心目标

> **让用户付钱。** 所有视觉/文案/交互/效果都只服务这一个目的——不是为了好看，不是炫技，是让用户掏钱包。回答不了「它把用户推向 CTA 吗」的元素，一律删。

---

## 设计 DNA（五维，生成时自动内嵌）

> 详细数值/代码集中在 **Step4 的可粘贴 prompt**（唯一真相源）。本节只讲原则与查表。

### D1 · 视觉：3 秒收割注意力

**首屏 800ms 加载时序**（决定用户是否继续看）：

| 时间 | 动作 |
|------|------|
| 0ms | 背景 #0a0a0a 立即出现（无白屏） |
| 0-200ms | 粒子/光晕淡入 opacity 0→0.6 |
| 200ms | Hero 标题滑入 y:40→0，600ms，ease:[0.16,1,0.3,1] |
| 280ms | 副标题 stagger +80ms |
| 360ms | CTA 出现，shimmer 开始循环 |
| 400ms | cursor spotlight 激活 |
| 600ms | 稳定，进入探索 |

**Pattern Interrupt 钩子**（首屏必含 ≥1 个，让用户停下）：A 动态标题词替换(typewriter) / B 光源跟随鼠标(cursor glow 600px) / C 数字进视口滚动(0→12,847) / D 低帧暗色动态背景。

**Dark Luxury 视觉系统**：

```css
/* 背景层级（下→上）*/
L0 #0a0a0a
L1 noise: SVG feTurbulence opacity:0.035（颗粒=品质）
L2 grid: linear-gradient(rgba(255,255,255,0.04) 1px,transparent 1px) 40px
L3 hero glow: radial-gradient(ellipse 80% 50% at 50% -10%, [品牌色/15%], transparent)
L4 内容区
L5 cursor spotlight: radial-gradient(600px at [mX] [mY], [品牌色/12%], transparent 70%)

/* 色彩 */
--bg-base:#0a0a0a  --bg-surface:#111118  --bg-elevated:#1a1a2e
--brand:[用户信息提取，默认#6366f1]
--text-hi:rgba(255,255,255,.95) --text-mid:.55 --text-lo:.30
--border:rgba(255,255,255,.08)  --border-brand:[品牌色@.30]

/* 排版 */
hero-title: 900, clamp(52px,7vw,108px), lh1.05
sub-title:  400, clamp(16px,2vw,22px), --text-mid
body:       16px, lh1.75, max-w62ch
label:      12px, ls0.12em, uppercase
```

**赌场感四要素**：① 多层同时运动（粒子慢漂 2-3px/s + cursor glow + 卡片 hover 浮起）② 有机 easing（禁 linear/ease-in-out；主动效 `cubic-bezier(0.16,1,0.3,1)`，弹窗 `spring(400,30)`）③ 深度系统（卡片 hover: `translateY(-6px) scale(1.02)` + shadow + 品牌色边框，300ms）④ 品位控制（同屏运动 ≤3、颜色 ≤2、字体 ≤2，每个效果须能说出"推进注意力去哪"）。

**性能预算**：60fps；粒子桌面 ≤80 / 移动 ≤30；同时 ≤2 CSS + 1 JS animation；`will-change:transform`；scroll reveal 用 IntersectionObserver。

**效果选择矩阵**（agent 查表，不自由发挥）：

| 区域 | 必选 | 条件选 |
|------|------|--------|
| Hero | cursor spotlight + 加载 stagger | 有数据→粒子背景；无参考→typewriter |
| 功能区 | hover 深度 + scroll reveal | ≥4 功能→Bento；<4→横排 |
| 数据/指标 | CountUp + 进视口触发 | 总是加 |
| 主 CTA | shimmer + hover translateY(-2px) | 总是加 |
| 定价卡 | glassmorphism + 中间档 scale(1.05) | 总是加 |
| 全局 section | Framer Motion whileInView stagger | 总是加 |
| 背景 | noise + grid + hero glow | 总是加 |

**视觉禁区**（看到即拒）：`transition:all`（须精确指定属性）/ 无意义旋转装饰 / 前景多色渐变 / 字重差 <200 / 背景动效 <30fps。

### D2 · 文案：过目不忘

**一句话定位公式**（所有文案主脑，不一定上页）：`[我们是]唯一一个[针对谁][做什么][而非竞品那样]的[品类]`。

**标题 5 规则**：① 具体>抽象（"每周省 11 小时会议"）② 数字>形容词（"转化率 1.2%→7.8%"）③ 反差制造张力（"会议录了，但没人听——直到你用这个"）④ 能大声读出来不别扭 ⑤ 用户语言非产品语言（"你说，它写，不用复听"）。

**Enemy Framing**：每页隐含一个反派——不是竞品（不点名），是旧方式/旧痛苦（"告别会后疯狂回忆刚才说了啥"）。用户看到反派立刻"你懂我"。

**核心价值 3 次重复**：Hero 标题（感性）→ 功能区某条（理性验证）→ 终极 CTA 前（行动触发）。

**文案精度**（生成时逐条检查）：

| 元素 | 要求 |
|------|------|
| Hero 标题 | ≤10 字(中) / ≤8 词(英) |
| 副标题 | ≤25 字，说清"谁用+得到什么" |
| CTA 按钮 | ≤6 字，动词+结果；禁 了解/探索/体验/注册/提交 |
| 功能描述 | ≤12 字/条，"让你[结果]"；禁 支持/提供/具备 |
| 引语 | 具体结果+真名+职位；禁泛化评价 |
| 全删词 | 欢迎使用/功能强大/一站式/赋能/生态 |

### D3 · 效果叙事（每个效果有存在理由）

| 效果 | 对用户的潜台词 |
|------|---------------|
| cursor spotlight | 「页面在感知你」→ 互动感 |
| 加载 stagger | 「内容是为你精心安排的」→ 品质 |
| CountUp | 「数字真实，刚算完」→ 可信 |
| 卡片 hover 浮起 | 「点这里」→ 降摩擦 |
| shimmer CTA | 「按钮在等你」→ 召唤行动 |
| scroll reveal | 「往前走有新内容」→ 鼓励探索 |
| 粒子背景 | 「品牌有能量」→ 氛围 |
| gradient text | 「这是最重要的」→ 强调 |

**组合原则**：层次分离（背景层慢动/中间层触发动/前景层进场一次后静止/交互层实时但不抢前景）；节奏控制（同屏运动 ≤2、scroll 触发点错开、每区一个主角效果）；整体感（全站同一 easing + 同一品牌色 + 同一边框透明度规范 → 像一部电影不是一堆零件）。

### D4 · 心理战术：感知→付费每步推进

**战术时序**（按 scroll）：

| 位置 | 战术 |
|------|------|
| 首屏 0-100vh | Pattern Interrupt 锁注意 + Enemy Framing 共鸣 + 单一 CTA |
| 信任区 100-200vh | 社会认同（具体数字+logo+真人引语）；CountUp 进视口滚动制造"刚算完"现场感 |
| 解决方案 200-300vh | 功能 ≤4，说结果不说功能；损失厌恶（"不用再…""永远不会…"）；呼应 Enemy |
| 定价 300-400vh | 锚定（最高档居左/先渲染）；中间档 scale(1.05)+「最受欢迎」；稀缺（"本月仅余 N 个名额"，N<20 才可信）；最低档"免费开始"不要信用卡 |
| 终极 CTA 末屏 | 峰终定律（情感峰值非信息堆砌）；重复首屏痛点闭环；唯一 CTA 无分叉 |

**沉默异议处理**（用户不会说出口的话）：

| 异议 | 处理 |
|------|------|
| 真的有用吗 | 具体化结果（"第一周 3 个付费用户"） |
| 太贵了 | 锚定转换（"全职设计师 $8000/月，这个 $29"） |
| 以后再说 | 稀缺损失（"早期价格明天结束"） |
| 适合我吗 | 渐进承诺（"不用信用卡，免费试 14 天"） |
| 没效果咋办 | 去风险（"30 天无理由退款"，放 CTA 旁不是页脚） |

**信任叠加 5 层**（缺哪层漏哪类用户）：L1 视觉质感 → L2 可验证数字 → L3 真人结果(头像+名+职+司) → L4 知名 logo(灰度) → L5 退款保障+免费试(CTA 附近)。

### D5 · 转化漏斗一致性

进入 → 3 秒被钩住(D1) → 标题共鸣"这是我"(D2) → 信任建立(D4 L2-5) → 异议消除(D4) → 单一 CTA → 转化。每步在页面须有对应区域，顺序不能乱。

**邮件捕获 Fallback**（针对"有兴趣不付钱"）：放 hero CTA 下方一行（"还没准备好？先看案例 →"）；只问邮件不问姓名；价值交换给免费资源/案例，不是"订阅新闻"。

## Agent 执行协议（调用 /v0 必走完）

### Step 1 · 任务分类

| 输入类型 | 动作 |
|----------|------|
| 改样式/颜色/文案/间距 | Design Mode（Option+D），Apply 才计费，告知操作步骤后结束 |
| 代码报错/bug | Fix with v0（20 次/天免费），先用免费额度 |
| 生成新页面/组件 | → Step 2 |
| 浅色/B2B 后台/非 landing | 保留 D2/D4/D5，仅 D1 色彩换浅色方案 → Step 2 |

### Step 2 · 品牌色提取

① 用户本次提到 → 直接用；② 历史/文件中有 → 用那个；③ 没有 → 默认 `#6366f1` 并注明"可告诉我品牌色"。
提取后：`glow=品牌色@0.12-0.15`，`border=@0.30`，`gradient=品牌色→色相+30°`。

### Step 3 · 选模型

| 任务 | 模型 |
|------|------|
| 微调/改一下 | v0 Mini（$1/$5 per 1M） |
| 完整组件/单页 | v0 Pro（$3/$15） |
| 全栈/多文件/数据库 | v0 Max（$5/$25） |
| 继续已有 chat | 任意，缓存命中省 10x input |

### Step 4 · 生成 prompt（直接输出，零占位符，可粘贴）

**固定 4 模块，一个不漏：**

```
【技术栈】
Next.js 14 App Router + TypeScript + Tailwind + Framer Motion + shadcn/ui
移动端优先，响应式，完整可运行，无占位文字。

【视觉 DNA】
背景：#0a0a0a + SVG noise(opacity:0.035) + 40px grid(rgba(255,255,255,0.04))
      + hero radial-gradient([品牌色]/15%, transparent, top20%)
品牌色：[Step2值]，用于 glow/border/gradient
卡片：bg-white/5 backdrop-blur-md border-white/8，hover:border-[品牌色]/30 translateY(-6px) scale(1.02) shadow(0 20px 60px black/50)，300ms cubic-bezier(0.16,1,0.3,1)
标题：font-black clamp(52px,7vw,108px) lh1.05 gradient-text([品牌色]→[偏移色])
正文：text-white/55 text-base max-w-[62ch]

【效果 — 按矩阵选择，代码级精确】
✅ 加载序列：标题0→副标题80→CTA160→装饰240ms，y:30→0 opacity:0→1 ease:[0.16,1,0.3,1]
✅ cursor spotlight：mousemove→radial-gradient(600px,[品牌色]/12%,transparent70%)覆盖hero
✅ Framer Motion whileInView stagger：staggerChildren:0.08，子元素 y:30→0 duration:0.6
✅ CTA shimmer：::after translateX(-100%→100%)，500ms ease，overflow:hidden
✅ 卡片深度：hover translateY(-6px) scale(1.02)+shadow+边框变品牌色
[按矩阵追加：有数据→CountUp(react-countup+enableScrollSpy)；功能≥4→Bento；hero无参考→粒子背景canvas(50-80点,0.3-0.8px/frame,连线<120px,移动端减半)]

【页面结构 — 按转化漏斗，顺序不能乱】
Hero(100vh)：主标题[痛+结果暗示,≤10字] / 副标题[谁+用+得到什么,≤25字] / 主CTA[动词+结果,≤6字,shimmer,h52px] / CTA下方"不用信用卡·免费14天·随时取消" / Pattern Interrupt[D1选1]
信任区(100-200vh)：用户数字(CountUp) / 3个logo(灰度hover变彩) / 2条引语(具体结果+真名+职位+头像占位)
解决方案(200-300vh)：≤4功能，Bento(≥4)或横排(<4)，每条"让你[结果]"+lucide图标 / Enemy framing 呼应(与Hero痛点闭环)
定价(300-400vh)：3档，最高档居左(锚定)，中间档 scale(1.05)+「最受欢迎」/ 每档功能≤5条+CTA / 稀缺"早期价格·本月仅余12名额" / 最低档CTA下"30天无理由退款"
终极CTA(footer前·情感峰值)：重复Hero痛点(闭环) / 单一CTA无其他链接 / 正下方退款+隐私承诺(≤1行)
Footer：仅版权+隐私+条款，不放博客/文档/社交

移动端：标题 clamp(36px,8vw,52px)，CTA w100% h52px / 汉堡菜单全屏 z9999 / 移除cursor glow→hero固定品牌色 radial(居中@0.20) + 标题下 border 脉冲(0.3↔0.8, 2s) + 卡片 :active 深度 / 粒子≤30无连线
```

### Step 5 · 泄漏点审计 + 输出

**生成完逐条检查（页面上的每个元素：推进 CTA，还是分散注意力？后者删）：**

```
□ 导航链接 ≤5？（博客/文档不进主导航）
□ 全页仅 1 个主 CTA 方向？（第二个指向别处的→删）
□ Footer 仅版权+隐私？
□ 退款保障在 CTA 下方 1-2 行内，不只在页脚？
□ 邮件捕获 fallback 存在？（hero CTA 下方次级入口）
□ 功能 ≤4 条？（超出放 FAQ）
□ 移动端 CTA h≥52px + w100%？粒子 ≤30？
□ 每个效果能回答"它推进了什么"？（回答不了→删）
□ 「了解更多」类无目的链接→全删
```

**输出格式：**

```
模型：v0 [Mini/Pro/Max]，因为：[一句话]

━━━ 粘贴到 v0 ━━━
[Step4 完整 prompt]
━━━━━━━━━━━━━

[可用 Design Mode 替代的部分→操作步骤]
省钱：[节省了什么]
```

## 速查

### 输入方式（越具体越省 credits）

| 输入 | 效果 | 建议 |
|------|------|------|
| Figma 链接 | 读 design token(色/间距/结构) | 最优先 |
| 截图/图片 | 读图生代码 | 省 2-3 轮 |
| 网站 URL | v0 自动截图分析 | 竞品参考直接丢 |
| 文字 prompt | 按 Step4 模板 | 越具体越省 |

**Figma 工作流**：每区域独立 frame（navbar/hero/features/pricing 分开）→ 每次只传 1 个 → 贴 URL 读 token（比截图保真）。

**GitHub 集成**：sidebar→Git→Connect 私有 repo；自动建分支 `v0/main-xxx` 不推 main；Publish→PR→merge→新 chat 继续。

**MCP 接入**：
```bash
claude mcp add --transport http v0 https://mcp.v0.dev --header "Authorization: Bearer $V0_API_KEY"
```
